Agent Messages: the tab bar

The real macOS title bar and menus (SwarmTitlebar.swift), drawn with sample tabs by tool/agent_messages_preview.swift. In every scene lamp and desktop have Agent Messages on, while website and notes have it off. Traffic lights are grey because the render window is never brought to the front, and tooltips can't be captured.

What changed from your review

  • No ⌘1/⌘2/⌘3 on tabs. The shortcuts still work, and holding ⌘ no longer changes the tabs.
  • ⇄ has no strike-through: grey when off, colored when on. The color is the terminal theme's magenta, which no other status uses.
  • While agents message each other, the status slot (where the spinner, ✓ and ? sit) shows an animated ⇄ for 15 seconds after the last message, then goes back to working, done or question.
  • At rest, names use the whole tab again. On hover, a name only moves left as far as ⇄ and × need.
